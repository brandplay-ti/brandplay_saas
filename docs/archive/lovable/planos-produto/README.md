# Planos do editor do Lovable (histórico)

Planos de funcionalidade escritos no editor do Lovable enquanto o BrandPlay era
desenvolvido lá. Ficavam em `.lovable/plan/`, pasta que o editor lia e
escrevia; foram movidos para cá quando o projeto deixou o Lovable (ADR-0001,
ADR-0006).

São registro do que motivou cada funcionalidade — não especificação viva. As
migrations `0009` e `0010` citam estes arquivos pelo caminho antigo
(`.lovable/plan/...`); migration aplicada não se edita, então a referência
fica como está e aponta para esta pasta.
